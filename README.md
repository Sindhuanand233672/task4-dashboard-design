# Task 4 – Dashboard Design (Power BI)

## 📌 Objective
The objective of this task is to design an **interactive dashboard for business stakeholders** that helps in understanding sales performance and making data-driven decisions.

---

## 🛠 Tools Used
- **Power BI Desktop**
- **Dataset:** Superstore Sales Dataset (Kaggle)

---

## 📊 Dataset Description
The Superstore dataset contains sales transaction data including:
- Order Date
- Sales
- Profit
- Category
- Region
- Customer and Product details

This dataset was used to analyze overall business performance.

---

## 📈 KPIs Used
The following Key Performance Indicators (KPIs) were used in the dashboard:
- **Total Sales**
- **Total Profit**
- **Sales Trend over Time**
- **Category-wise Sales Performance**

---

## 🎛 Dashboard Features
- **KPI Cards** for quick summary of Sales and Profit  
- **Line Chart** for time-series sales analysis  
- **Bar Chart** for category-wise sales comparison  
- **Slicers** for interactivity:
  - Region
  - Order Date  
- Consistent and clean color theme

## 🔍 Key Insights
- Sales show an increasing trend over the years  
- Technology category contributes the highest sales  
- Sales and profit vary significantly across regions  

---

## ✅ Conclusion
This dashboard provides an interactive and visual representation of business performance, enabling stakeholders to analyze sales trends, profitability, and category performance effectively.
